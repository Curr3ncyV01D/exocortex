# ExoCortex Frontend

## Локальный запуск

Понадобятся Node.js 24 LTS, npm и установленное Python-окружение проекта.
Команды ниже рассчитаны на PowerShell.

В первом терминале из корня репозитория запусти FastAPI.

```powershell
.\.venv\Scripts\python.exe -m uvicorn src.main:app --host 127.0.0.1 --port 8000
```

Во втором терминале из корня репозитория запусти Vite.

```powershell
cd frontend
npm.cmd ci
npm.cmd run dev
```

Открой [ExoCortex](http://127.0.0.1:5173/). Выбери чат в боковой панели
и ветку в шапке истории. Кнопка **Новый чат** создаёт чат и открывает его ветку
`main`. Для создания чатов и просмотра истории ключ Gemini не нужен.

Vite проксирует запросы `/api/` на FastAPI. История загружается
с `include_inactive=true`, поэтому скрытые реплики остаются на своих местах
с отметкой **Вне контекста**.

## Тесты и сборка

Из папки `frontend` выполни:

```powershell
npm.cmd test
npm.cmd run build
```

Тесты из `tests/` проверяют API-клиент и взаимодействие с интерфейсом
с подменой HTTP-ответов. Сборка проверяет типы TypeScript и создаёт статические
файлы в `dist/`.
Прокси Vite предназначен для локальной разработки.
