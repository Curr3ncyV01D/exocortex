# ExoCortex Frontend

## Локальный запуск

Понадобятся Node.js 24 LTS, npm и установленное Python-окружение проекта.
Команды ниже рассчитаны на PowerShell.

В первом терминале из корня репозитория запусти FastAPI.

```powershell
.\.venv\Scripts\python.exe -m uvicorn src.main:app --host 127.0.0.1 --port 8000
```

Во втором терминале из корня репозитория запусти Vite.

```powershell
cd frontend
npm.cmd ci
npm.cmd run dev
```

Открой [ExoCortex](http://127.0.0.1:5173/). Выбери чат в боковой панели
и ветку в шапке истории. Кнопка **Новый чат** создаёт чат и открывает его ветку
`main`. Для создания чатов и просмотра истории ключ Gemini не нужен.

Vite проксирует запросы `/api/` на FastAPI. История загружается
с `include_inactive=true`, поэтому скрытые реплики остаются на своих местах
с отметкой **Вне контекста**.

На широком экране разделители меняют размеры островков, а кнопка **Проводник**
открывает зарезервированную панель. Размеры и открытое состояние запоминаются
в браузере. На узком экране список открывается кнопкой **Чаты** в шапке.

## Отправка сообщений

- **Run** или **Ctrl+Enter** сохраняет сообщение и запускает Gemini.
- **Добавить** сохраняет сообщение без генерации. После одного или нескольких
  добавлений нажми **Run** с пустым полем, чтобы ответить на последний активный
  вопрос. Скрытые реплики и выжимки слияний не блокируют этот запуск.
- Если Gemini вернул ошибку после сохранения вопроса, **Повторить генерацию**
  повторяет вызов модели для той же реплики и вершины. При превышении лимита
  сократи сохранённый вопрос через **Редактировать**. Черновик хранится отдельно
  для каждой ветки в локальном хранилище браузера.

Для живой генерации настрой серверный ключ Gemini по [инструкции](../docs/how-to/test-gemini-with-swagger.md).

## Действия над сообщениями

Наведи курсор на реплику или перейди к её кнопкам клавишей Tab. На сенсорном
экране кнопки видны сразу. Через **Редактировать** можно изменить исходный
Markdown. Если реплика общая для нескольких веток, интерфейс попросит
подтвердить правку и покажет число затронутых веток.

Меню реплики позволяет создать ветку от этой точки, скрыть реплику из
контекста или вернуть её, а также скопировать Markdown. Маска действует
во всех ветках, где находится сообщение.

В боковой ветке кнопка **Слить в main** открывает подтверждение. После слияния
приложение откроет `main`, где выжимка появится как отдельный узел истории.
Кнопка **Перегенерировать ответ** на последнем активном ответе создаёт ветку
от исходного вопроса. Если форк создан, а генерация вернула `502` или `413`,
интерфейс откроет новую ветку и предложит повторить вызов модели или сократить
сохранённый вопрос.

## Тесты и сборка

Из папки `frontend` выполни:

```powershell
npm.cmd test
npm.cmd run build
```

Тесты из `tests/` проверяют API-клиент и взаимодействие с интерфейсом
с подменой HTTP-ответов. Сборка проверяет типы TypeScript и создаёт статические
файлы в `dist/`.
Прокси Vite предназначен для локальной разработки.

## Повтор отправки после обрыва соединения

Если приложение не смогло подтвердить сохранение сообщения, повтори отправку
с тем же текстом. Браузер повторно использует ключ отправки этой ветки,
в том числе после перезагрузки с сохранённым черновиком. Если сервер уже
записал реплику, он вернёт её прежний ID.

## Браузерная приёмка

Из папки `frontend` после установки зависимостей запусти:

```powershell
npx.cmd playwright install chromium
npm.cmd run test:e2e
```

Если уже установлен Microsoft Edge, можно выбрать его через
`$env:PLAYWRIGHT_CHANNEL = 'msedge'` и запустить `npm.cmd run test:e2e`.
Playwright поднимает отдельный Vite на порту `5178` и FastAPI на порту
`8017` с SQLite в памяти и подменой Gemini. Нужна Python-среда `.venv` в
корне проекта. Тест теряет ответ уже после записи реплики, перезагружает
страницу, повторяет отправку и проверяет генерацию, форк и слияние.

## Измерение покрытия

Для фронтенда запусти `npm.cmd run test:coverage` из папки `frontend`.
Отчёт в HTML появится в `coverage/`. Для бэкенда выполни из корня:

```powershell
.\.venv\Scripts\python.exe -m pip install "coverage>=7.6,<8"
.\.venv\Scripts\python.exe -m coverage run --branch --source=src -m pytest
.\.venv\Scripts\python.exe -m coverage report
```
