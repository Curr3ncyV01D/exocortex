# Как пользоваться миникартой истории

Миникарта первой версии реализована для настольной компоновки. Откройте чат и нажмите **«Проводник»** в верхней области левой колонки. Панель появится под списком чатов. Её высоту и ширину левой колонки можно менять разделителями. Заголовки со шевронами сворачивают островки; кнопки открытия свёрнутых островков появляются наверху слева. Список чатов также сворачивается перетаскиванием разделителя вверх; Проводник занимает почти всю доступную высоту под постоянной плашкой. Перетаскивание вниз до границы сворачивает Проводник. Обратное движение разделителя разворачивает свёрнутый островок; раскрытие кнопкой восстанавливает последнюю пропорцию двух открытых островков. Их кнопки независимы: открытие Проводника не открывает закрытый список чатов, и наоборот. Если закрыты оба, остаётся верхняя плашка с кнопками открытия.

## Что показывает карта

- Заполненный круг — пользователь; окружность — модель; ромб — сводка слияния.
- Main голубая. Остальные ветки используют стабильные цвета из спокойной палитры; при большом числе веток цвета могут повторяться.
- Общая история main остаётся голубой. Активная ветка выделяется яркостью и толщиной связей; общие предки тоже участвуют в выделении.
- Сплошная линия показывает родителя сообщения. Пунктир показывает подтверждённый источник слияния и проходит по боковому коридору со скруглёнными поворотами, избегая длинного наложения на основную историю. У старых слияний неизвестный источник не дорисовывается.
- Скрытое сообщение остаётся на карте с приглушённым пунктирным контуром. Узлы без текущей ветки тоже остаются видимыми.
- Возле вершины показываются названия веток, указывающих на неё. Полное сокращённое имя доступно в подсказке.

## Управление

Кнопка «Новый чат» доступна даже при свёрнутом списке и открывает отдельный диалог, не уменьшая Проводник. Ошибка сохраняет введённое название для повторной отправки.

Одинарный клик выделяет сообщение и закрепляет его превью. Наведение или клавиатурный фокус показывают роль, время и короткий текст; для слияния — имя исходной ветки. Карточка появляется в противоположной половине панели, чтобы не перекрывать узел под курсором. Многоточие означает, что сообщение длиннее показанного фрагмента; у «Изменено» есть подсказка с датой последней правки. Клик по пустому фону снимает выделение.

Камеру перемещают зажатой средней кнопкой мыши либо комбинацией **Space + ЛКМ**. Колесо меняет масштаб. Кнопки `+`, `−` и рамка из четырёх углов увеличивают, уменьшают и показывают весь граф. При первом открытии показывается окрестность HEAD активной ветки; закрытие панели сохраняет камеру в памяти отдельно для каждого чата. Перезагрузка страницы очищает эти положения.

Граф запрашивается только при открытии панели. Для обновления после изменения диалога используйте кнопку **«Обновить граф»**. Ошибка отображается внутри панели с кнопкой повтора и не блокирует основной чат.

## Границы Вехи 2

Переход к сообщению двойным кликом или Enter ещё не реализован: это Веха 3. Контекстного меню, выделения рамкой, редактирования и слияния из графа пока нет. Двойной клик не увеличивает масштаб.

Автоматическое обновление после операций чата и навигация через выбор подходящей ветки запланированы отдельно. Контракт backend описан в [SPEC](../SPEC.md#524-компактный-граф-чата), этапы — в [трекере](../specs/001-explorer.md).
