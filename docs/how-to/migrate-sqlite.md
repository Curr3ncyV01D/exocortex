# Как подготовить SQLite к запуску ExoCortex

Команды выполняются из корня репозитория в PowerShell. Нужны готовое Python-окружение `.venv` и зависимости из `requirements.txt`. Alembic, FastAPI и импортёр используют `DATABASE_URL` из окружения или `.env`. По умолчанию SQLite хранится в `data/exocortex.db`.

## Новая база или обновление уже версионированной базы

Останови работающий FastAPI. Для существующей базы сделай резервную копию перед обновлением. Затем выполни:

```powershell
.\.venv\Scripts\python.exe -m alembic upgrade head
.\.venv\Scripts\python.exe -m alembic current
```

Для новой базы Alembic создаст таблицы и полнотекстовый индекс FTS5 с триггерами. После успешной миграции можно [запускать приложение](../../frontend/README.md#локальный-запуск).

## База, созданная до Alembic

Останови ExoCortex и другие процессы, работающие с этим файлом SQLite. Один раз выполни:

```powershell
.\.venv\Scripts\python.exe -m scripts.adopt_legacy_db
.\.venv\Scripts\python.exe -m alembic upgrade head
```

Скрипт создаст резервную копию рядом с базой и выведет её путь. Он сравнит схему с ревизией `0001`, проверит внешние ключи и целостность FTS5 и только затем зарегистрирует ревизию. Если найдены расхождения, скрипт завершится с ошибкой. Для такой базы понадобится отдельный переход, соответствующий её фактической схеме.

Для пробного перехода укажи в `DATABASE_URL` путь к отдельной копии базы. Для SQLite используй расположение с прямыми слэшами, например `sqlite+aiosqlite:///C:/path/to/exocortex-copy.db`. После проверки убери временную переменную окружения или открой новый терминал.
